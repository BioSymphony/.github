# BioSymphony GitHub Profile

This repository drives the public organization profile for
[BioSymphony](https://github.com/BioSymphony).

GitHub renders the public organization profile from:

```text
profile/README.md
```

Keep this repository public-safe. Do not add secrets, private run records,
private datasets, unpublished biological data, pod IDs, network volume IDs,
internal planning notes, or raw logs.
