# BioSymphony GitHub Profile

This repository drives the public organization profile for
[BioSymphony](https://github.com/BioSymphony).

GitHub renders the public organization profile from:

```text
profile/README.md
```

Keep this repository safe for public release. Leave secrets, non-public run
records, non-public datasets, unpublished biological data, pod IDs, network
volume IDs, non-release planning notes, and raw logs outside the repo.

## Profile Assets

`profile/assets/` contains the banner and desktop and mobile versions of the
agent workflow and example toolchain diagrams. The `.excalidraw` files are editable diagram sources.
The banner is a conceptual illustration; it contains no experimental data.

The profile uses absolute asset URLs so the images resolve on the organization
page. Publish the README and its assets together. The `<picture>` element
selects vertical diagrams on narrow screens.
